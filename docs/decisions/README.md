# Decision Records

Decision records document cross-cutting choices that affect Dayly's product, UX, domain, architecture, security, or future compatibility.

- [`ADR_INDEX.md`](ADR_INDEX.md) — approved phase decision references, current PHASE 0E contract references, and future ADR format.

Decisions should state the context, options considered, chosen direction, consequences, affected boundaries, and status. Do not invent historical decisions; link to the approved source documents and commits. A superseding decision should link to what it replaces.
