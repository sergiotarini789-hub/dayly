# Dayly Documentation

This directory is organized by the kind of decision or artifact being documented:

- [`product/`](product/) — product concepts, scope, and domain definitions.
- [`architecture/`](architecture/) — future system-boundary and technical architecture decisions.
- [`ux/`](ux/) — future information architecture, interaction, and experience decisions.
- [`decisions/`](decisions/) — cross-cutting decisions and decision records.

The current product source of truth is the root [`PRODUCT_SPEC.md`](../PRODUCT_SPEC.md). Empty categories are represented by a short README until their phase begins.
